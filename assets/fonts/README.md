# Font Nom Na Tong (tùy chọn)

Ứng dụng có thể chạy khi chưa có font này; hệ điều hành/Trình duyệt sẽ dùng font CJK khả dụng. Font Nom Na Tong chỉ là fallback cho các glyph Hán-Nôm đặc thù và sẽ được đăng ký trong `pubspec.yaml` khi file tồn tại.

Nguồn chính thức: https://github.com/nomfoundation/font/releases/tag/v5.18
Tải thủ công: https://github.com/nomfoundation/font/releases/download/v5.18/NomNaTong-Regular.ttf
SHA-256 bản v5.18 mong đợi: `37bd8506257d0905d499395e7f0bc2b6a2ae619dbb635a82ea0905b75b2ff5f3`

Giữ lại giấy phép NomFoundation MIT trong `LICENSE-NomNaTong.txt` nếu bạn tải và dùng font.
